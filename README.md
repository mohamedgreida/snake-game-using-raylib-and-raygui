# 🐍 Snake Game

A modern, object-oriented 2D Snake game built using **C++**, **Raylib**, and **Raygui**. This project features a stylized, desktop-integrated overlay design with a borderless transparent window, smart predictive obstacle spawning, dynamic difficulty options with a hover state UI, and synchronized audio mechanics.

## 🎮 Game Controls

| Key / Input | Action |
| :--- | :--- |
| `W` / `Up Arrow` | Steer Snake Up |
| `A` / `Left Arrow` | Steer Snake Left |
| `S` / `Down Arrow` | Steer Snake Down |
| `D` / `Right Arrow` | Steer Snake Right |
| `Escape` | Pause / Unpause current session |
| `Mouse Left-Click & Hold` (Top Bar) | Drag window viewport around your desktop |
